Privacy Policy

Dystopia Connect Publisher · Last updated 24 November 2026

Dystopia Connect Publisher ("the tool") is a personal tool that uploads the Dystopia Connect channel's own animated YouTube Shorts to that channel. It is used only by the channel's owner. This policy explains what data it uses.

What the tool accesses

When the channel owner signs in with Google, the tool asks for two YouTube permissions:

  • Upload videos (youtube.upload): to upload the owner's own finished videos and their thumbnails.
  • View the YouTube account (youtube.readonly): to read the channel's name and each uploaded video's status, so the tool can confirm an upload succeeded.

The tool uses YouTube API Services. It does not access viewers' data, comments, subscribers, analytics, email, contacts or any other Google service.

What is stored, and where

  • A Google sign-in token, stored only on the owner's own computer, readable only by the owner's user account.
  • A local record of uploaded videos (file name, YouTube video ID and link, upload time), stored only on the owner's computer.

Nothing is sent to any server other than Google's and YouTube's own. This website has no cookies, analytics or tracking.

Sharing

The tool does not sell, share or transfer any data to anyone. The only data sent anywhere is the owner's own videos and their titles, descriptions, tags and thumbnails, sent to YouTube to publish them.

Removing access and data

  • Access can be revoked at any time at Google Account → Third-party connections (also reachable through Google security settings).
  • Revoking access makes the stored token useless. The local token and upload record can be deleted from the owner's computer at any time.
  • Uploaded videos are managed in YouTube Studio like any other video.

Google and YouTube policies

By using the tool you are using YouTube, so the YouTube Terms of Service apply, and Google's handling of data is covered by the Google Privacy Policy.

Changes

If this policy changes, the new version will be posted on this page with a new date.
